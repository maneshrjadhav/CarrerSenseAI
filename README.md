# CareerSense AI – Intelligent Resume Screening & Career Guidance System

CareerSense AI is an intelligent web application designed to automate resume screening and provide tailored career guidance using NLP, TF-IDF vectorization, and cosine similarity.

## System Modules
1. Resume Screening
2. NLP-based Resume & Job Description Processing
3. TF-IDF Vectorization
4. Cosine Similarity Matching
5. Match Score
6. Skill Extraction
7. Skill Gap Analysis
8. Career Roadmap Generation
9. Interview Question Prediction

## Tech Stack
- **Frontend:** React, Vite, JavaScript, CSS, Lucide React
- **Backend:** Python, Flask, Flask-CORS
- **Database:** MySQL ONLY (SQLAlchemy, mysql-connector-python)
- **PDF Extraction:** PyMuPDF (`fitz`)
- **NLP / ML:** Python, NLTK, scikit-learn (TF-IDF, Cosine Similarity), bcrypt
